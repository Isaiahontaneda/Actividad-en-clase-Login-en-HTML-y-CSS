# Login AdminExpress

Actividad en clase: réplica de una página de login usando HTML y CSS, con diseño responsive.

## Descripción

El diseño se adapta a tres tamaños de pantalla:

- **Escritorio:** pantalla dividida en dos columnas. A la izquierda el panel azul con el nombre "AdminExpress" y a la derecha el formulario de login.
- **Tableta:** mismo diseño con tamaños de texto y de formulario reducidos.
- **Móvil:** una sola columna, sin el panel azul, con el botón a todo el ancho y el texto "Sign Up".

## Técnicas utilizadas

- HTML semántico (`main`, `section`)
- CSS Grid para la estructura de dos columnas
- Media Queries (`max-width: 1024px` y `max-width: 768px`) para el diseño responsive
